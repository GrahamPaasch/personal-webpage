Pixel Opera — pilot

Real operas staged as 16-bit RPG cutscenes (spec 40). Four scenes; each sung scene is published three ways so the orchestra (A: real sampled orchestra, B: console-style sound) and the English translation (A: fresh plain modern, B: a 19th-century public-domain version) can be judged side by side. The dance has no words, so audio A/B only.

Resolve Cycles

A 5-minute CFAR-inspired exercise for finding the value hidden inside frustration.

1. Capture Frustration
Name something that has been bugging you lately - a situation, a person's behavior, something that keeps annoying you.
2. Feel the Charge
Sit with it for a moment. Where do you feel it in your body? What is the quality of the irritation?
3. Extract the Value
Underneath this frustration, what do you actually care about? The thing that is bothering you points at something you value. What is it?
autonomy competence authenticity connection growth impact craftsmanship
4. State the Value
Say it simply: I care about ___. Then check whether it resonates in your body.

5. Check the Shift
Return to the original frustration and notice whether naming the value changes the felt sense.
Moment of recognition
Now think about the original frustration again. Has something shifted? Does it feel different now that you have named what you care about?
6. Repeat or Finish
You can extract another value from a new frustration, or continue to summary.
7. Summary
Frustration to value pairs
Pattern recognition
Self-compassion
Values are facts about yourself, not things to judge.
Integration suggestions
Focusing: Stay with the strongest value and ask what it wants you to notice more deeply.
Internal Double Crux: Use this when two values conflict and you feel internally split.
Goal Factoring: Align your goals with the values you just named so effort feels cleaner.
Hamming Questions: Given these values, ask what your real bottleneck is right now.
Accumulated pairs
Each loop turns irritation into a clearer statement of what matters to you.
